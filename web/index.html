AI benchmark + training environment

AI finds the rule.
It can't apply it exactly.

Stickler is a puzzle test where one wrong square fails the whole answer. Every puzzle is brand new, so no model has seen it. The best model we tested still slipped on 1 in 5.

How it works

A hidden rule changes a grid. The model sees 4 examples and has to draw the next answer, square by square.

01

4 examples

Each one shows a grid before and after the secret rule.

02

A new grid

Nobody tells the model the rule. It has to work it out, then apply it here.

03

Every square checked

One wrong square out of 900 is a fail. That single slip is what we measure.

right answer → Sonnet 5.5, 1 square off

It is fair

  • No trick questions. A puzzle is thrown away if a second simple rule also fits the examples.
  • Every case is shown. If the test needs "an empty square with 5 neighbours", the examples have one too.
  • Self-checked. A perfect solver scores 100%, copying the input scores 0%.

What it found

  • Spotting the rule is easy. Opus solved every 3-step chain puzzle.
  • Applying it exactly is not. Even Fable failed 11 of 28 Game of Life puzzles.
  • Smaller models give up. Haiku solved 0 Game of Life puzzles and often asked for a hint.
  • Memory beats evidence. When the rule was one number off the famous Game of Life, Fable and Opus mostly applied the famous one anyway.

Why it's different

Most tests ask what a model knows. Stickler asks whether it can do careful work without a single slip.

The slip, isolated

Models write the right rule, then miss 1 square of 462. We catch exactly that.

Can't be memorised

Puzzles come from a seed. Make a million, none leak into training data.

Test and train

The same puzzles score a model and reward it during RL training.

Every answer public

All prompts and replies are saved. Check any result yourself.

Use it

Python 3.9+, nothing else to install. Works with any OpenAI-style API: OpenAI, Gemini, DeepSeek, OpenRouter, or a local model with Ollama.

# install pip install git+https://github.com/mayankvashishtt/stickler # run the 74 leaderboard puzzles on your model export OPENAI_API_KEY=sk-... stickler bench --model gpt-5-mini --workers 8 # harder levels stickler bench --model gpt-5-mini --suite steps # rule applied 3 times stickler bench --model gpt-5-mini --suite trap # rule one number off a famous one stickler bench --model gpt-5-mini --suite fix # fix a near-miss answer # other providers: set the address export OPENAI_BASE_URL=https://openrouter.ai/api/v1
# every seed is a fresh puzzle: unlimited training data from stickler.gen import generate from stickler.episode import GridEnv for seed in range(100_000): env = GridEnv(generate(seed=seed, depth=2, size="m"), max_turns=3) prompt = env.reset() while True: reply = my_model(prompt) # your policy prompt, reward, done, info = env.step(reply) # 1.0 if perfect, else 0.5 x squares right if done: break
# get the 74 puzzles as one file: id, prompt, answer stickler export --out stickler-74.jsonl # score your answers: one JSON per line, {"id", "reply"} or {"id", "grid"} stickler score my_predictions.jsonl

Results land in results/<model>/. To get on the leaderboard, open a pull request with that folder.
